# Futureal Test Plan

## Objective

The objective of this testing effort is to verify the functionality and stability of Futureal's core gameplay systems through manual testing.

## Features Tested

- Player movement
- Jumping and platforming
- Shooting and combat
- Enemy interactions
- Player health and death
- User interface
- Level progression
- Game state transitions

## Testing Types

### Functional Testing

Core gameplay systems were tested against their expected behavior.

### Exploratory Testing

Additional testing was performed by interacting with the game in unexpected or edge-case scenarios.

## Test Environment

- Operating System: Windows 11
- Game: Futureal
- Engine: Godot 3.5.2

## Completion Criteria

Testing was considered complete after all planned test cases were executed and results were documented.
