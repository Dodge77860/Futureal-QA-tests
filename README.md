Futureal QA Testing Portfolio
Overview

This repository contains a manual QA testing portfolio project for Futureal, an open-source 2D platform shooter developed in Godot. The project demonstrates the creation and execution of QA documentation, including a test plan, test cases, test execution results, and defect reporting.

About Futureal

Futureal is a 2D action platformer where the player progresses through levels by navigating obstacles, engaging enemies, and reaching level objectives. The game was selected because it is open source, playable within a reasonable amount of time, and contains multiple gameplay systems that can be tested using standard QA methodologies.

Why This Project Was Tested

The purpose of this project is to develop and demonstrate practical software testing skills relevant to game QA positions. The project focuses on learning how to:

Analyze game functionality
Create structured test documentation
Design and execute test cases
Identify and document defects
Record and communicate testing results
Testing Approach

Testing was performed using manual functional and exploratory testing techniques.

Functional Testing

Core game systems were tested against their expected behavior, including:

Player movement
Jumping and platforming
Combat and shooting
Enemy interactions
User interface elements
Level progression
Game state transitions
Exploratory Testing

Additional testing was performed by interacting with the game in unexpected or edge-case scenarios to identify potential defects, usability concerns, and unintended behavior.
